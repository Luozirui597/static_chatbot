# S5 — Correction after a licensed inference

Kind: fixed
Calls: 4
Focus: Q1 licenses one inference; T2 only processes the correction; Q2 must not reuse the old B-C fact and must preserve the negation.

## T1 (teach)

We are doing a short fictional logic puzzle. A, B, and C are only labels. In this puzzle, "links" is a made-up relation; do not use outside knowledge about links.

I teach you these facts:
- A links to B.
- B links to C.

Puzzle rule: for these tokens, if X links to Y and Y links to Z, then X links to Z.

## Q1 (query)

Does A link to C? Use only what I taught. If you infer it, mark it.

## T2 (correction)

Correction: I was wrong about B links to C. B does not link to C. Everything else I taught is still current.

## Q2 (recheck)

Now report what is currently taught about A, B, and C, and whether A links to C follows. Use only the corrected facts.
