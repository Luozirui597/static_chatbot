# Teachable Agent 更新说明 · 2026-11-06

记录范围为 2026-10-31 至 2026-11-06（Asia/Shanghai），包含上周末。本文件区分正式功能、独立实验、既有真实结果和本次提交前的离线复验。

## 1. 正式页面的教学策略

**状态：已实现并接入，已做代表性真实网页验收。**

- Receive teaching 中增加 Standard、A、B、A+B 会话级选择，刷新后保留；Corrective 中隐藏，切回恢复。
- A 允许按老师明确教授的规则进行一次受限推导；B 可以请求一次聚焦补教，但不推导；A+B 结合这两项能力，并限制直接索取目标答案。
- 增加策略切换端点、会话设置与消息快照存储；旧消息保持未知快照，不追溯改写。
- 普通回答、固定检索、通用检索和澄清共用实际策略与语言约束。
- 正式 Safari 的三个策略会话共 8 次真实调用通过当批功能核对。它们不构成长时间稳定性证明。

主要位置：`backend/teaching_strategies.py`、`backend/prompts/`、`backend/chat_service.py`、`backend/models.py`、`backend/database.py`、`frontend/teaching-strategy.js`、`frontend/app.js`。

## 2. 按需教学历史检索

**状态：已接入；混合依据和长会话场景已有真实验证。**

- 普通历史继续使用同会话最近 20 条存储消息，再过滤助手；当前用户请求独立追加。
- 固定关系路径优先，通用路径区分窗口内已有答案、缺事实、缺解释、明确追溯和对象不明。
- 通用检索 v2 支持“窗口内有部分依据，窗口外查找解释”，避免决策字段契约冲突导致检索前失败。
- 保留教师来源、版本、请求/路由诊断和更正配对；限制精确 profile/model，并区分模型截断、决策失败、检索和最终生成。
- 长会话批次 68 次发送、71 次模型调用中，成功找回早期教学、采用更正后流程，窗口内答案不触发检索。一条双对象澄清回复虽走对路由，提问聚焦性仍未达标。

主要位置：`backend/programmatic_history/`、`backend/general_history/`、`backend/chat_service.py`、`backend/llm_client.py`、`.env.example`。

## 3. 回复语言约束与语言偏差实验

**状态：语言校验已接入；原对照实验及必要输入已归档。**

- 生成前冻结目标语言，区分显式要求、持续偏好、单轮覆盖与输入语言。
- 普通、固定检索、通用检索和澄清在助手写库前共用语言校验；错误语言不保存助手回复，保留已保存的用户消息。
- 公式、代码、固定标签与可核对引文按保留规则处理；无法安全确定语言的输入返回明确错误。
- 真实网页验收的 17 条成功首答均符合当批语言或原文保留规则；该批没有自然发生的错语，不能据此计算真实错语拦截率。拒绝路径依据隔离回归。
- 独立语言实验：49 条普通教学样本和 7 个控制目标，各跑三条件，共 168 次真实调用。中文回复分别为基线 12/49、翻译示例 4/49、翻译历史说明 8/49；只翻译示例有改善，仍未消除偏差。

主要位置：`backend/reply_language.py`、`backend/chat_service.py`、`tests/test_reply_language.py`、`experiments/language_language_probe/`。

语言工具从项目工作目录归档到仓库；只将夹具、仓库和本地配置的定位改为相对路径，并调整运行说明。冻结提示词、输入文本、168 项计划、哈希与原始结果保持原样。归档工具采用独立目录运行，不混入整个仓库的 pytest 收集。

| 策略验证与集成 | `experiments/strategy_stability/` | 核对来源、关系方向、否定、更正、撤销、条件、例外、推导额度及询问权限；临时数据库验证助手与状态原子提交、错误与并发隔离 |
| 新版原子受控任务 | `experiments/strategy_stability/controlled_v1/` | 完成 32 会话、44 次真实调用；四组共同输入与结构化合同，保留原始候选和拒绝；未接正式页面 |

新版受控实验中，A+B 的两个预设缺口场景均发生真实询问、补教和推导。原始关系初筛放行 39/44；正文复核发现 B 两条解释错误后，最终正文复核正确数为 37/44。错误来自补教后未刷新的缺口上下文，不能把原始候选合法当作整条最终正文正确。

Standard 的共同合同引用了组名，但其策略正文未同样显式声明身份；五条候选被拦截的结果存在实验设计混淆。下一版应修正身份声明，不能用此批结果评价正式 Standard 的一般表现。

本次不修改 v1 冻结任务、提示词或哈希，也不补跑旧批次。原始结果不能与旧 32/80 叙事实验合并计算。
